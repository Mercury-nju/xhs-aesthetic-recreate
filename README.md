# xhs-aesthetic-recreate

医美行业小红书帖子复刻 Skill：读取参考帖，逐张保留服装、姿态、表情、局部眼部状态、背景与构图，生成同结构的原创图文示意，并对文案做同义同风格改写。

## Installation

Copy `xhs-aesthetic-recreate/` into your Codex skills directory, or invoke the skill from its `SKILL.md`.

## Scope

The skill separates fictional visual demonstrations from real treatment cases, does not fabricate medical claims, and does not publish automatically.
